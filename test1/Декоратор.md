Чтобы добавить к классу `tiQueueSet` разграничение прав доступа и многопоточность, не изменяя исходный класс, можно использовать паттерн **Декоратор** (Decorator). Этот паттерн позволяет динамически добавлять новую функциональность к объекту, не изменяя его исходный код. В вашем случае это позволит создавать различные комбинации функциональности (например, с многопоточностью, с правами доступа или без них) в зависимости от требований программы.

---

### **Шаги для реализации:**

1. **Создать интерфейс `ITiQueueSet`:**
   Определим интерфейс, который будет реализовывать как базовый класс `tiQueueSet`, так и все декораторы.

   ```cpp
   class ITiQueueSet
   {
   public:
       virtual ~ITiQueueSet() = default;

       virtual tiQueue *get(IDTYPE ID) = 0;
       virtual IDTYPE add(tiQueue *QueuePtr) = 0;
       virtual int del(IDTYPE ID) = 0;
       virtual bool isFull() = 0;
   };
   ```

2. **Изменить класс `tiQueueSet`, чтобы он реализовывал интерфейс `ITiQueueSet`:**
   Теперь `tiQueueSet` будет реализовывать этот интерфейс.

   ```cpp
   class tiQueueSet : public ITiQueueSet
   {
   public:
       static tiQueueSet *getInstance()
       {
           static tiQueueSet instance;
           return &instance;
       }

       tiQueue *get(IDTYPE ID) override { /* реализация */ }
       IDTYPE add(tiQueue *QueuePtr) override { /* реализация */ }
       int del(IDTYPE ID) override { /* реализация */ }
       bool isFull() override { /* реализация */ }

   private:
       tiQueueSet() {}
       // Остальные методы и поля...
   };
   ```

3. **Создать базовый декоратор:**
   Базовый декоратор будет реализовывать интерфейс `ITiQueueSet` и хранить ссылку на обёрнутый объект.

   ```cpp
   class TiQueueSetDecorator : public ITiQueueSet
   {
   protected:
       std::shared_ptr<ITiQueueSet> wrapped;

   public:
       TiQueueSetDecorator(std::shared_ptr<ITiQueueSet> wrapped) : wrapped(wrapped) {}

       tiQueue *get(IDTYPE ID) override { return wrapped->get(ID); }
       IDTYPE add(tiQueue *QueuePtr) override { return wrapped->add(QueuePtr); }
       int del(IDTYPE ID) override { return wrapped->del(ID); }
       bool isFull() override { return wrapped->isFull(); }
   };
   ```

4. **Создать декораторы для многопоточности и прав доступа:**

   - **Декоратор для многопоточности:**
     Добавим мьютекс для обеспечения потокобезопасности.

     ```cpp
     #include <mutex>

     class ThreadSafeTiQueueSet : public TiQueueSetDecorator
     {
     private:
         std::mutex mtx;

     public:
         ThreadSafeTiQueueSet(std::shared_ptr<ITiQueueSet> wrapped) : TiQueueSetDecorator(wrapped) {}

         tiQueue *get(IDTYPE ID) override
         {
             std::lock_guard<std::mutex> lock(mtx);
             return wrapped->get(ID);
         }

         IDTYPE add(tiQueue *QueuePtr) override
         {
             std::lock_guard<std::mutex> lock(mtx);
             return wrapped->add(QueuePtr);
         }

         int del(IDTYPE ID) override
         {
             std::lock_guard<std::mutex> lock(mtx);
             return wrapped->del(ID);
         }

         bool isFull() override
         {
             std::lock_guard<std::mutex> lock(mtx);
             return wrapped->isFull();
         }
     };
     ```

   - **Декоратор для разграничения прав доступа:**
     Добавим проверку прав доступа перед выполнением операций.

     ```cpp
     class AccessControlTiQueueSet : public TiQueueSetDecorator
     {
     private:
         bool hasAccess(IDTYPE userID)
         {
             // Логика проверки прав доступа
             return true; // Заглушка
         }

     public:
         AccessControlTiQueueSet(std::shared_ptr<ITiQueueSet> wrapped) : TiQueueSetDecorator(wrapped) {}

         tiQueue *get(IDTYPE ID) override
         {
             if (!hasAccess(ID)) throw std::runtime_error("Access denied");
             return wrapped->get(ID);
         }

         IDTYPE add(tiQueue *QueuePtr) override
         {
             if (!hasAccess(QueuePtr->getOwnerID())) throw std::runtime_error("Access denied");
             return wrapped->add(QueuePtr);
         }

         int del(IDTYPE ID) override
         {
             if (!hasAccess(ID)) throw std::runtime_error("Access denied");
             return wrapped->del(ID);
         }

         bool isFull() override
         {
             return wrapped->isFull();
         }
     };
     ```

5. **Использование декораторов:**
   Теперь вы можете комбинировать декораторы в зависимости от требований программы.

   ```cpp
   int main()
   {
       // Базовая реализация
       auto baseQueueSet = std::make_shared<tiQueueSet>(tiQueueSet::getInstance());

       // Добавляем многопоточность
       auto threadSafeQueueSet = std::make_shared<ThreadSafeTiQueueSet>(baseQueueSet);

       // Добавляем разграничение прав доступа
       auto accessControlQueueSet = std::make_shared<AccessControlTiQueueSet>(threadSafeQueueSet);

       // Использование
       tiQueue *queue = accessControlQueueSet->get(123);
       return 0;
   }
   ```

### **Преимущества подхода:**

1. **Гибкость:**
   Вы можете комбинировать декораторы в любом порядке, создавая нужную функциональность для конкретной программы.

2. **Открытость/закрытость:**
   Вы можете добавлять новую функциональность, не изменяя исходный класс `tiQueueSet`.

3. **Тестируемость:**
   Декораторы можно легко тестировать изолированно.

4. **Модульность:**
   Каждый декоратор отвечает за одну задачу (например, многопоточность или права доступа), что соответствует принципу единственной ответственности (SRP).

---

### **Примеры комбинаций:**

1. **Только многопоточность:**
   ```cpp
   auto threadSafeQueueSet = std::make_shared<ThreadSafeTiQueueSet>(baseQueueSet);
   ```

2. **Только права доступа:**
   ```cpp
   auto accessControlQueueSet = std::make_shared<AccessControlTiQueueSet>(baseQueueSet);
   ```

3. **Многопоточность и права доступа:**
   ```cpp
   auto combinedQueueSet = std::make_shared<AccessControlTiQueueSet>(
       std::make_shared<ThreadSafeTiQueueSet>(baseQueueSet)
   );
   ```

4. **Без дополнительной функциональности:**
   ```cpp
   auto baseQueueSet = std::make_shared<tiQueueSet>(tiQueueSet::getInstance());
   ```

Использование паттерна **Декоратор** позволяет добавлять функциональность (например, многопоточность и права доступа) к классу `tiQueueSet`, не изменяя его исходный код. Это делает систему гибкой, расширяемой и соответствующей принципам SOLID.
