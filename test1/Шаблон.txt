Шаблонный тип нужен:
- для количества очередей в Массиве (unsigned)
- для размера очереди (unsigned)
- для типа переменной в Очереди (любой числовой)


Количество очередей (длина сегмента и количество сегментов) и размер очереди задаются unsigned константами, по которым надо определить подходящий тип переменной.
То есть, мы берем максимальную переменную типа unsigned для входного числа и определяем по этому числу тип переменной для шаблонной переменной.

Тип переменной в Очереди задаётся явно.
