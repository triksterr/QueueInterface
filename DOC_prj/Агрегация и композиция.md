Агрегация и композиция — это два типа отношений «целое-часть» (has-a) в объектно-ориентированном программировании. Разница между ними заключается в степени зависимости объекта-части от объекта-целого.  

### **1. Агрегация**  
Агрегация означает, что объект-часть (компонент) может существовать **отдельно** от объекта-целого. Это слабая связь между объектами.  

#### **Пример агрегации:**
```cpp
#include <iostream>

class Engine {
public:
    void start() { std::cout << "Engine started\n"; }
};

class Car {
private:
    Engine* engine; // Car агрегирует Engine, но не владеет им
public:
    Car(Engine* eng) : engine(eng) {}

    void start() { engine->start(); }
};

int main() {
    Engine engine;
    Car car(&engine); // Передаём уже существующий объект
    car.start(); // Engine started

    return 0;
}
```
Здесь `Car` **не владеет** объектом `Engine`, а только использует его. Двигатель может существовать отдельно от машины.

---

### **2. Композиция**  
Композитный объект **полностью владеет** своими частями, и их существование зависит от объекта-целого. Когда объект-целое уничтожается, уничтожаются и все его части.  

#### **Пример композиции:**
```cpp
#include <iostream>

class Engine {
public:
    void start() { std::cout << "Engine started\n"; }
};

class Car {
private:
    Engine engine; // Car владеет Engine
public:
    void start() { engine.start(); }
};

int main() {
    Car car;
    car.start(); // Engine started

    return 0;
}
```
Здесь `Car` **создаёт** и **владеет** объектом `Engine`. Когда `Car` уничтожается, `Engine` уничтожается автоматически.

---

### **Ключевые различия**  
| Фактор | Агрегация | Композиция |
|--------|------------|-------------|
| **Жизненный цикл** | Объект-часть может существовать независимо | Объект-часть уничтожается вместе с целым |
| **Владение** | Объект-целое не владеет объектом-частью | Объект-целое владеет объектом-частью |
| **Связь** | Слабая связь (указатель, ссылка) | Сильная связь (прямое включение в качестве поля) |

Если объект-часть может использоваться в нескольких объектах-целях и не должен автоматически удаляться при удалении целого — это **агрегация**. Если объект-часть существует **только** внутри целого — это **композиция**.
