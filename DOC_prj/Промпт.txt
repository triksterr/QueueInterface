Какие стандартные механизмы С++ можно использовать для реализации класса магазина (FIFO) фиксированной длины с мандатным доступом к его методам. Тип данных - целочисленный, доступ - желательно, по указателю как в обычном массиве. Лучше чтобы в основе лежал динамический массив для обеспечения скорости доступа.

Методы:
- запись через регистр - запись всегда
- запись напрямую - ? если есть место?

- добавление нового значения - push()
- чтение значения с перемещением указателя ("удалением элемента") - pop ()
- чтение значения по индексу в очереди - []
- получить полный размер очереди - size()
- получить длину заполненного участка - length()

- очистить всю очередь clear() : все = 0
- удалить очередь - del() - ? деструктор
- создать очередь - create(с параметрами) - конструктор (определить, кто именно создал и дать ему права???)

- прямое чтение по индексу в исходном массиве - getValue()
- прямая запись  по индексу в исходном массиве - setValie(,)


- ключи мандатного доступа - генерация
- ID - static
- имя - генерация
