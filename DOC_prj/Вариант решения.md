Для реализации класса магазина (FIFO) фиксированной длины с целочисленным типом данных, доступом по указателю (как в обычном массиве) и высокой скоростью доступа, можно использовать следующие стандартные механизмы C++:

1. **Массив фиксированного размера**:
   - Используйте `std::array` или обычный массив (`int[]`) для хранения данных. Это обеспечит высокую скорость доступа к элементам.

2. **Индексы для управления FIFO**:
   - Используйте два индекса: один для указания на начало очереди (`head`), другой для указания на конец (`tail`). Это позволит эффективно добавлять и удалять элементы.

3. **Мандатный доступ**:
   - Используйте `private` для скрытия внутренней реализации и `public` для предоставления безопасного интерфейса.
   - Для доступа по указателю можно предоставить метод, возвращающий указатель на внутренний массив, или перегрузить оператор `[]`.

4. **Обработка переполнения и опустошения**:
   - Используйте исключения (`std::overflow_error`, `std::underflow_error`) или возврат кода ошибки для обработки граничных случаев.

5. **Кольцевой буфер**:
   - Реализуйте логику кольцевого буфера, чтобы эффективно использовать память и избежать копирования данных при достижении конца массива.

### Пример реализации

```cpp
#include <iostream>
#include <array>
#include <stdexcept>

template <size_t N>
class FixedLengthFIFO 
{
public:
    // Конструктор
    FixedLengthFIFO() : head(0), tail(0), size(0) {}

    // Добавление элемента в очередь
    void push(int value) 
	{
        if (size >= N) 
		{
            throw std::overflow_error("Queue is full");
        }
        buffer[tail] = value;
        tail = (tail + 1) % N;
        size++;
    }

    // Удаление элемента из очереди
    void pop() 
	{
        if (size == 0) 
		{
            throw std::underflow_error("Queue is empty");
        }
        head = (head + 1) % N;
        size--;
    }

    // Доступ к элементу по индексу (как в массиве)
    int& operator[](size_t index) 
	{
        if (index >= size) 
		{
            throw std::out_of_range("Index out of range");
        }
        return buffer[(head + index) % N];
    }

    // Получение текущего размера очереди
    size_t get_size() const 
	{
        return size;
    }

    // Проверка, пуста ли очередь
    bool is_empty() const 
	{
        return size == 0;
    }

    // Проверка, заполнена ли очередь
    bool is_full() const 
	{
        return size == N;
    }

    // Доступ к данным через указатель (как в массиве)
    int* data() 
	{
        return buffer.data();
    }

private:
    std::array<int, N> buffer; // Массив для хранения данных
    size_t head; // Индекс начала очереди
    size_t tail; // Индекс конца очереди
    size_t size; // Текущий размер очереди
};

int main() 
{
    FixedLengthFIFO<5> fifo;

    // Добавляем элементы
    fifo.push(10);
    fifo.push(20);
    fifo.push(30);

    // Доступ по индексу
    std::cout << "Element at index 1: " << fifo[1] << std::endl; // 20

    // Удаляем элемент
    fifo.pop();
    std::cout << "Element at index 0 after pop: " << fifo[0] << std::endl; // 20

    // Доступ через указатель
    int* ptr = fifo.data();
    std::cout << "First element via pointer: " << ptr[0] << std::endl; // 20

    // Проверка на заполненность
    fifo.push(40);
    fifo.push(50);
    fifo.push(60); // Ошибка: очередь переполнена

    return 0;
}
```

### Объяснение:
1. **`std::array<int, N>`**:
   - Используется для хранения данных. Это обеспечивает высокую скорость доступа и фиксированный размер.

2. **Кольцевой буфер**:
   - Индексы `head` и `tail` используются для управления началом и концом очереди. При достижении конца массива они "переходят" на начало, создавая кольцевой эффект.

3. **Мандатный доступ**:
   - Методы `push`, `pop`, `operator[]` и `data` предоставляют безопасный интерфейс для работы с очередью.
   - Метод `data()` возвращает указатель на внутренний массив, что позволяет работать с данными как с обычным массивом.

4. **Обработка ошибок**:
   - Используются исключения для обработки переполнения, опустошения и выхода за границы.

5. **Доступ по указателю**:
   - Метод `data()` возвращает указатель на внутренний массив, что позволяет использовать его как обычный массив.

### Преимущества:
- Высокая скорость доступа к элементам благодаря использованию массива.
- Эффективное использование памяти благодаря кольцевому буферу.
- Безопасный интерфейс с проверкой граничных случаев.

### Недостатки:
- Фиксированный размер очереди, заданный на этапе компиляции.
- Необходимость вручную управлять индексами `head` и `tail`.

Этот подход идеально подходит для задач, где важны производительность и фиксированный размер очереди.
