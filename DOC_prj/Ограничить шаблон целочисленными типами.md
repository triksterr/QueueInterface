Как ограничить шаблон целочисленными типами?

В C++ можно ограничить шаблон целочисленными типами с помощью механизма **статических утверждений** (`static_assert`) и **типозависимых проверок** (`std::is_integral`). Это позволяет на этапе компиляции убедиться, что шаблонный параметр является целочисленным типом.

### Пример реализации шаблонного класса, ограниченного целочисленными типами

```cpp
#include <iostream>
#include <type_traits> // для std::is_integral
#include <queue>
#include <stdexcept>

template <typename T>
class FixedLengthFIFO {
    static_assert(std::is_integral<T>::value, "Template parameter must be an integral type");

public:
    // Конструктор, принимающий максимальную длину очереди
    FixedLengthFIFO(size_t max_size) : max_size(max_size) {}

    // Добавление элемента в очередь
    void push(const T& value) {
        if (queue.size() >= max_size) {
            throw std::overflow_error("Queue is full");
        }
        queue.push(value);
    }

    // Удаление элемента из очереди
    void pop() {
        if (queue.empty()) {
            throw std::underflow_error("Queue is empty");
        }
        queue.pop();
    }

    // Получение элемента из начала очереди
    T front() const {
        if (queue.empty()) {
            throw std::underflow_error("Queue is empty");
        }
        return queue.front();
    }

    // Проверка, пуста ли очередь
    bool empty() const {
        return queue.empty();
    }

    // Проверка, заполнена ли очередь
    bool full() const {
        return queue.size() >= max_size;
    }

    // Получение текущего размера очереди
    size_t size() const {
        return queue.size();
    }

private:
    std::queue<T> queue;
    size_t max_size;
};

int main() {
    FixedLengthFIFO<int> fifo(3); // Работает, так как int — целочисленный тип

    fifo.push(1);
    fifo.push(2);
    fifo.push(3);

    std::cout << "Front: " << fifo.front() << std::endl; // 1
    fifo.pop();

    std::cout << "Front: " << fifo.front() << std::endl; // 2
    fifo.pop();

    std::cout << "Front: " << fifo.front() << std::endl; // 3
    fifo.pop();

    if (fifo.empty()) {
        std::cout << "Queue is empty" << std::endl;
    }

    // Ошибка компиляции, так как double не является целочисленным типом
    // FixedLengthFIFO<double> invalid_fifo(3);

    return 0;
}
```

### Объяснение:
1. **`static_assert`**:
   - Используется для проверки условия на этапе компиляции.
   - Если условие ложно, компиляция завершится с ошибкой.

2. **`std::is_integral<T>::value`**:
   - Это типозависимая проверка из библиотеки `<type_traits>`.
   - Возвращает `true`, если `T` является целочисленным типом (например, `int`, `short`, `long`, `unsigned int` и т.д.).

3. **Ошибка компиляции**:
   - Если попытаться использовать тип, не являющийся целочисленным (например, `double` или `std::string`), компилятор выдаст ошибку благодаря `static_assert`.

### Поддерживаемые типы
Шаблон будет работать с любыми целочисленными типами, включая:
- `int`
- `unsigned int`
- `short`
- `unsigned short`
- `long`
- `unsigned long`
- `long long`
- `unsigned long long`
- `char`
- `unsigned char`
- `int8_t`, `uint8_t`, `int16_t`, `uint16_t`, `int32_t`, `uint32_t`, `int64_t`, `uint64_t` (из `<cstdint>`)

### Альтернативный подход: концепты (C++20)
Если вы используете C++20, можно использовать **концепты** для более современного и читаемого способа ограничения шаблонов:

```cpp
#include <concepts> // для std::integral

template <std::integral T>
class FixedLengthFIFO {
    // Реализация класса
};
```

Этот код делает то же самое, что и `static_assert`, но с использованием концептов, которые являются частью современного C++.
